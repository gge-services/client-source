# The 13 nonstandard ES5 Command constructors

The official October 16 Game.bundle includes 13 Command constructors that initialize fields on a provisional this reference before invoking the base constructor. TypeScript and ES2015 native derived classes cannot assign to this before super(). These sources were previously excluded from the reconstructed Command project.

The AST reconstructor now recognizes only their verified shape: an initial receiver alias, assignment of ordinary fields before the CONSTRUCTOR_HACK marker, a single ES5 superclass call, and optionally a field assignment after that call. It evaluates each original field initializer into a temporary value before super(), keeps the CONSTRUCTOR_HACK evaluation in its original order, calls super(), and then assigns the previously evaluated values to native class fields. Compound post-super assignments remain after the base call. It never converts an unknown constructor based only on structural similarity.

Ancestry proof validates the original canonical SHA-256 of every ancestor and the complete inheritance chain. The two supported roots are SimpleCommand and CollectableRendererList. Their original constructors only assign the documented own fields; intermediate constructors are verified delegating or belong to the 13 specifically recognized shape families. If a child field collides with any ancestor initializer or property descriptor name, the transformation fails closed. All 13 converted classes carry a parent-proof record with hashes and the pre-super fields in their .evidence.json files.

A runtime comparison constructs every original ES5 class and its compiled TypeScript equivalent with real canonical parent constructors loaded in an isolated VM. Each original and reconstructed class yields identical own fields and inherited field values in that test environment; AIsoCommand.isExecuted also has verified getter/setter behavior. There are explicit negative tests for inherited field collisions and unverified ancestry. This covers the exercised constructor behavior, not all possible monkeypatches, environment-specific getters, network events, or complete in-game effects. The metadata retains fullRuntimeEquivalent=false.

The ShowHowToDoQuestconditionCommand source also uses logical assignment operators and a go(callback) implementation that intentionally reads additional arguments from the arguments object. TypeScript 2.9 cannot parse ||= and rejects extra go arguments based on its single formal parameter. The generator rewrites identifier logical assignments without duplicating evaluation and adds a TypeScript interface overload for the verified variadic call path. The overload emits no JavaScript.

Result: all 701 of 701 officially observed Command classes are reconstructed and compile with TypeScript 2.9. The updated October 16 to October 25 ABI evidence finds 2,237 unchanged method/getter/setter signatures and all 701 original constructor arities matching. This does not establish a standalone browser client. The TypeScript project has 102 other source-backed class implementations and 778 unresolved type-only imports, of which 474 are direct and 304 are transitive. A complete runtime with these imports and browser globals is still missing.
